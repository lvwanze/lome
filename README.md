# LOME

> **面向重要人际关系的双人情感深层交互与关系成长平台的设计与实现**  
> 基于 Flutter + 腾讯云开发 CloudBase + 大语言模型的跨端情感陪伴应用

LOME 面向青年人，重点服务异地、高压力忙碌的挚友或恋人，打造亲密关系专属数字化沟通空间。项目以 **记录、陪伴、沟通** 为三大核心价值，坚持「AI 作为辅助而非替代」的设计原则。AI 仅承担理解、提醒、整理、引导工作，把表达权和决定权留给关系双方。

## 🛠 技术栈

### 客户端

- **Flutter + Dart**：一套代码支持 Android / iOS 跨端运行
- **Lottie 动画**：实现治愈系交互动效
- **本地加密存储**：草稿、敏感信息本地加密落盘

### 后端云服务（腾讯云开发 CloudBase）

- **云函数**：业务逻辑处理
- **云数据库**：持久化业务数据
- **云存储**：图片、静态资源管理
- **AuthService**：统一 Token 鉴权，双人 ID 数据隔离，防止越权访问

### 通信与任务调度

- **WebSocket / MQTT**：同屏共读实时翻页、批注同步
- **Cron 定时任务 + 消息队列**：慢信定时投递、失败重试

### AI 应用层

- 大语言模型 API、提示词工程
- NLP 情绪识别、文本生成、话题生成
- 用户授权机制：未经授权不读取用户私密内容

### 安全与合规

- Token 身份校验，双人数据访问隔离
- 端侧加密存储，计划引入国密 SM4
- 机器 + 人工双层内容审核，用户举报入口
- 遵循《个人信息保护法》《人工智能拟人化互动服务管理暂行办法》

### 工程化

- Git 版本管理，模块化分支开发
- 完整产品计划书、数据库设计、API 接口文档
- 按 P0 / P1 / P2 优先级迭代开发

## 🎯 Prompt 意图控制与 AI 代码约束策略

> 评审维度：方法创新性与意图控制  
>
> 本项目大量业务代码由 AI 辅助生成，团队采用多层约束，避免 AI 输出不可控代码。

1. **上下文约束**：向 AI 输入需求时，前置传入项目现有架构文档、数据模型、接口定义，强制 AI 遵循现有模块划分，禁止 AI 随意新增文件、随意自定义数据表。
2. **架构约束**：强制要求 AI 遵守分层：`core 公共层 → service 服务层 → model 模型层 → page 页面层 → widget 组件层`；禁止 AI 编写页面与业务逻辑耦合的代码。
3. **安全约束**：每次生成后端 / 鉴权相关代码，明确要求必须带上双人 ID 鉴权校验，拒绝无权限校验的代码。
4. **迭代约束**：不一次性要求 AI 输出完整大模块，而是拆分为小任务迭代生成；AI 输出代码后人工审查，再进行 Bug 调试，遇到异常通过多轮 Prompt 引导 AI 定位并修复问题。
5. **输出边界约束**：AI 仅负责编码实现，**产品需求、数据表、业务规则全部由人预先定义**。

## 🚀 10 分钟极速复现指南

> ⚠️ **重要提示**：本项目依赖腾讯云开发 CloudBase 环境 + 大模型 API 密钥，仅前端代码可以本地打开浏览；完整业务跑通需要自行准备云资源。
>
> 预估总耗时：8–10 分钟。

### 环境版本要求

- Flutter SDK：`3.19.0` 及以上
- Dart：`3.3.0` 及以上
- Node.js：`18.x`（部署云函数使用）
- 腾讯云 CloudBase 环境：自备独立环境 ID
- 大模型 API：自备 API-Key

### 步骤 1：拉取代码（约 1 分钟）

```bash
git clone https://github.com/lvwanze/lome.git
cd lome
```

### 步骤 2：安装前端依赖（约 2 分钟）

```bash
flutter pub get
```

> ✅ 到此步骤完成，即可打开 IDE 浏览全部前端代码、UI 组件、业务逻辑，不需要密钥。

### 步骤 3：配置环境变量模板（约 2 分钟）

复制环境模板，填入自己的资源凭证：

```bash
cp .env.example .env
```

使用编辑器打开 `.env`，填写 CloudBase 环境 ID、大模型 API Key。

### 步骤 4：部署腾讯云云函数（约 4 分钟）

1. 进入 `cloudfunctions` 目录。
2. 使用 CloudBase CLI 将各个云函数依次上传部署到自己的云开发环境。
3. 在云开发控制台配置数据库权限规则，开启登录鉴权。

### 步骤 5：启动 App（约 1 分钟）

```bash
flutter run
```

### 复现说明

1. 如果没有腾讯云资源，评审可以仅执行步骤 1–2，阅读全部源码。
2. AI 相关能力目前处于方案设计阶段，代码为接口封装框架。
3. 所有真实密钥不会提交到仓库，必须由使用者自行填充。
